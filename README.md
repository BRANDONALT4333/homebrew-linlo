
# Linlo — Homebrew Tap

Linlo is a simple yet INCREDIBLY  powerful  findutils wrapper file searcher made by EclipseGMD.

## Installation

Install Linlo using Homebrew:

```bash
brew tap BRANDONALT4333/linlo
brew install linlo
```

## About Linlo

Linlo is a Bash-based file-searching utility built around findutils.

- **Developer:** EclipseGMD
- **Source code:** https://github.com/BRANDONALT4333/Linlo
- **Current formula version:** 1.1.0

## Platform Support

- **Linux:** Installation and testing through Homebrew on Linux.
- **macOS:** Support is intended but remains unverified on a real macOS system.

## Dependencies

- `findutils`

Homebrew installs the declared dependency automatically.
